# Using Sitka as an agent

- Start from `public/llms.txt` (every docs page, one line each) and `public/components.json` (each React component's import, props, tokens used, docs and Figma links). Both are generated by `npm run generate`; don't edit them by hand.
- Tokens: `src/tokens/tokens.json` is the only source. After changing it run `npm run generate` and commit the regenerated Swift, Figma variables and manifests; CI fails otherwise.
- Colour rules are enforced by `src/__tests__/color-decisions.test.ts`: status colours as text use `--status-*-text`, text on the accent uses `--on-accent`, destructive fills use `--danger-solid`.
